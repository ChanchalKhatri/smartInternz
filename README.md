# smartInternz Project :- 🎬 MovieSpace

MovieSpace is a movie database web application built using React. It allows users to search movies, browse categories, view movie details, and control the application using voice commands.

## 🚀 Features

* Search movies
* Browse movie categories
* View movie details and ratings
* Voice commands using Alan AI
* Responsive UI
* Modern Material UI design

## 🛠️ Tech Stack

* React.js
* Redux Toolkit
* React Router DOM
* Material UI
* Axios
* Alan AI
* Emotion

## 📦 Installation

```bash
git clone https://github.com/your-username/moviespace.git

cd moviespace

npm install

npm start
```
